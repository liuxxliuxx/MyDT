# v3.4 在线起点与neutral偏置修复

2026-09-11。独立代码包 `emotion_ssm/train/staged_v34`；v3.3训练模块和既有实验保留。

## 训练机制

- `calibration`及历史名称为`joint`的块只更新状态形成参数；传播参数冻结。
  `joint`在v3.4中表示交替训练里的更新器适配块，不再表示两个参数组一起更新。
- `fixed/readapt`只更新传播参数。每次抽到起点后，以当前参数重放最近32个事件，
  在`no_grad`下构造并detach起点，未来损失只能更新传播器。
- 所有阶段每250步最多重新生成一次完整对话前缀；每100步在每域一个固定训练对话上重放检测漂移。
  z MSE超过1e-5、fast/slow/relation平均分量MSE超过2e-5或固定头类别变化率超过2%时提前刷新。
  阈值是本次预先设定的工程参数，尚未证明为最佳值。单个探针对全训练分布的覆盖有限。
- 前缀刷新保留查询抽样器的随机状态和游标。起点始终来自完整对话历史，梯度仅截断到32个事件。
- 共享observer、固定教师、类别/VAD/强度头和观测校正覆盖参数保持冻结。
  当前有效观测上的向量保持损失与教师语义保持损失约束更新器，缺失观测不计入这些损失。

## 真实语义与neutral

总目标保留原向量误差，加入真实终点CE、有效VAD维度和有效强度损失，联合系数0.25。
当前语义保持系数0.1。EmotionTalk缺失的arousal/dominance不会成为监督。

类别CE权重只从当前训练对话池的唯一真实终点统计，分别按域和预测时距计算。
使用逆频率平方根，按该训练分布归一化后上限3；不支持类别权重为0。
查询抽样仍按域/时距/任务分配，没有额外类别过采样。每个池的计数、权重和来源写入`class_audit_block*.json`。
这些计数不是整个训练集的统计，换池时权重允许变化；不使用验证标签确定权重。

保留针对非neutral错判的margin实验入口，但本次系数为0。不会强行把预测类别比例变成均匀分布，
也不会把它调成验证集的类别比例。保持固定标签头，避免通过换头改变对照含义。

## 评测与模型选择

同一固定教师、标签头、24个验证对话和真实终点分别评测公共固定起点、完整在线重放、
更新中断、传感器缺失。强基线包括保持、纯衰减、训练均值、均值收缩、当前线性和历史线性。

每域、每时距输出宏F1/UAR、VAD/强度误差、每类召回、混淆矩阵、
`P(pred=neutral | y!=neutral)`以及neutral召回/精确率。
无标签的DualTalk不报告真实类别能力；没有32秒终点的数据域也不补造长期指标。

- `best_vector.pt`仅表示公共起点上的向量MSE最小。
- `best_semantic.pt`表示在线16/32秒各有效域的平均(F1+UAR)/2最高，仍是诊断模型。
- `best_deploy.pt`要求在线及两种缺失协议的长期F1/UAR/neutral召回不降低超过1个百分点，
  非neutral误判neutral不增加超过1个百分点，VAD/强度不恶化超过2%，各域/时距向量误差不恶化超过5%；
  长期F1不得明显低于自身保持，并要求在线长期平均F1比旧9750至少提高0.5个百分点。
  这些是验证门槛，不代表已经超过所有线性基线，更不代替独立测试。
