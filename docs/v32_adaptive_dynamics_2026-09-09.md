统一情感 Avatar v3.2：状态相关演化、持续双人反馈和混合遮挡（2026-09-09）

本次实现已同步到服务器3，按用户后续指示准备独立动力学实验，见 [服务器3运行记录](server3_v32_run_2026-09-09.md)。服务器1原来的 v3.1.3 生成训练保持原样。新结构和新遮挡策略需要独立实验，旧权重的评测不能当作本版结果。

核心实现为 `emotion_ssm/models/adaptive_flow.py`、`state_core.py` 和 `context_masking.py`。训练入口仍使用 `_v3.py`，token 协议继续为 `emotion-token-packets-v3.1`、checkpoint 格式继续为 4；权重内另外记录动力学、学习和生成 revision。

双方状态仍保存同一 affect 坐标下的 fast、slow、baseline，以及两个方向的 relation。观测器没有增加第二套情感空间。设 `x_i=[fast_i, slow_i]`、`z_i=fast_i+slow_i`，无新输入时的演化可写成：

```
dx_i/dt = [-D_i(x_i,x_j,r) + S_i(x_i,x_j,r)] x_i
          + B_i(x_i,x_j,r) tanh(W z_j)
dr_i/dt = rate_r * [target_i(x_i,x_j,r_i,r_j) - r_i]
```

`D_i` 是正的、状态相关的快慢衰减率；`S_i` 包含原快慢交换和新增低秩反对称跨维度作用；`B_i` 根据双方状态及关系生成反馈强度。每次内部积分都重新计算系数。训练结束后网络参数固定，但当前状态不同，实际演化矩阵和反馈强度仍会改变。共享参数使用角色相对输入，交换双方角色会交换输出。

这里的“维度”指共享 affect 的潜在坐标。模型没有预先规定某个神经元一定是悲伤或愤怒，VAD 和情感分类仍由已有标签头读出。跨维度作用提供学习这种关联的能力，不构成可解释语义的证明。

持续耦合有以下时间语义：

- 没有新事件、没有新音频时，已有双方状态仍持续相互影响，形成 A→B→A 的反馈路径。全部模态缺失时运行自主动力学；`decay_only` 保留为独立纯衰减对照。
- 新事件仍由存在门控和事件 ID 去重，只注入一次。新行为的外力仍按明确持续时间积分。持续状态反馈不会把历史文本重新编码成新事件。
- 外部每秒接收一次输入、输出新增 25 帧。内部默认最多 0.5 秒一步；这是数值积分精度设置，不要求每半秒采集新输入。
- 在线推进和 open-loop 预测调用同一个状态场。open-loop 只读取起点状态；conditional 只额外接收明确声明的 event/action，不读未来 affect。
- 查询点不改变积分路径；加入一个额外查询不会改变已有查询结果。非整数间隔分段执行只在数值误差范围内等价，不能沿用旧线性矩阵指数的“精确半群”表述。

为了限制自激，跨维度算子限制范数、消息和关系目标经过 tanh、衰减率保持正值。反馈允许情感偏移增长和累积，因此没有强制状态能量每一步下降。慢态仍可保存历史，是否真正利用历史需要验证，不能根据时间常数或非零梯度直接判断。

训练日志的 `current_state/adaptive/` 和 `learned_open_loop/h*/state/adaptive/` 新增：

| 指标 | 含义 |
|---|---|
| `cross_coordinate_drive_norm` | 当前状态下实际跨维度作用向量的范数 |
| `partner_feedback_norm` | 当前状态下持续 partner 消息对快慢态的作用范数 |
| `fast_rate_ratio`、`slow_rate_ratio` | 状态相关速率相对基础学习速率的比例 |
| `relation_drive_norm` | 当前关系目标产生的驱动量 |

这些指标用于检查作用通道是否消失，不作为需要人为最大化的损失。partner 的作用可以随上下文很弱；不强迫每个样本都产生显著影响。效果评测仍需关闭耦合、交换 partner 历史、清空历史等配对对照。

90% 的样本选择局部连续片段遮挡，各模态默认遮挡约 40%–70% 的有效 token；10% 选择丢弃一个或多个完整模态，并保留至少一个实际存在的模态。比例可配置，尚未证明 90/10 是最优比例。A0 监督分支和 Phase B 模态抽样也改为优先使用全部可用模态、少量覆盖其余六种子集，避免把旧的均匀模态丢弃再叠加到新重建视图上。

音频与同源韵律共用遮挡；同一时刻的 AU 与 FLAME 共用遮挡，只抽样一次。不同模态的片段位置可不同，允许从可见音频、文本、视觉推断缺失信息。teacher 和重建目标读取同一观测时刻的完整可见信息；不扩展到未来音频或未来文本。

整模态丢弃是真实的 availability mask 缺失，不把该模态全部替换为仍然可见的 mask token。被丢弃模态通过 affect 瓶颈的摘要目标训练；片段遮挡另外保留 token 重建。短序列遮挡数量取整；如果只剩一个依赖单元，保留可见证据，避免得到纯 mask 输入。自然缺失不会伪造成被遮挡的真实数据，身份未知的视觉必须使用缺失 mask。

A0 和联合生成辅助损失已接入新遮挡。FLAME 校准仍使用原有固定 A/T 教师和视觉专用重建目标，不在这个单路适配阶段随机删掉唯一被校准的视觉输入。干净视图的方差、协方差、样本间相似度和教师约束继续保留。遮挡更强不能替代防退化约束，也不能单独保证长时记忆被使用；完整对话状态、TBPTT 和多时距未来监督继续使用。

启动新的 `scripts/server1_v3_pipeline.py` 实验会默认使用本配置，并在 `experiment_protocol.json` 记录 flow 和 masking。已有 token 特征若来源、标签和时间版本一致，可以通过 `--reuse-token-root` 显式复用。完整验证新遮挡方案时，A0、校准、动力学和生成阶段应重新训练；新遮挡实验不能把旧 A0/校准导出标成已经完成的新上游。旧 checkpoint 可按原构造读取推理，新旧训练协议不能恢复同一个优化器。服务器3本轮固定旧表征、只训练新动力学，配置显式保留旧 A0 revision 和 `masking=null`。

本次没有改变动力学 best 的原始 affect MSE 选择规则。已有实验出现过该 MSE 下降而独立情感指标变差，因此评测必须同时比较固定标签头上的 VAD、分类和 intensity，检查多个保存点。新增结构不自动消除这个模型选择问题。

测试覆盖跨维度梯度、状态相关系数、无新输入时的双向反馈、关闭 partner 的隔离、角色交换、事件去重、未来信息隔离、不等间隔积分、长时间数值稳定、掩码比例与同源泄漏、新旧 checkpoint 协议以及四种生成对照的优化器更新。测试通过只表示实现满足这些合同；三数据集重训和独立语义/生成评测尚未执行。
