## 训练队列

入口为 `scripts/server1_v2_pipeline.py --run-id v2_retrain_20260907_gpu23`，使用 `nohup` 脱离 SSH 会话运行。流程：

1. 并行重建 EmotionTalk、IEMOCAP 的因果 A/T 特征。两者分别使用物理 GPU 2、3。
2. 双卡训练 A0 → Phase A → Phase B，种子 6666。
3. 为 DualTalk 生成时间对齐缓存，并双卡校准 FLAME 适配器。
4. 四种独立对照分别双卡训练 1,000 个优化步；每步全局 32 个有效新块。
5. 使用各自验证 best 评测 test/OOD。

这是正式 30,000 步、多种子实验之前的诊断流程。上游 A0/A/B 使用配置规定的 50 轮。任何阶段失败都会停止后续阶段并记录 `failed`，不会换用旧协议或旧缓存继续训练。
