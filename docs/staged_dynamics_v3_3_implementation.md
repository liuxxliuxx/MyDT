## 不变的约束

observer affect/reliability与观测覆盖参数冻结；旧权重只用于新实验初始化。所有主要对照使用相同初始化、数据清单、优化预算与评测查询。向量评测维持原stride目标集合，新增真实标签查询独立计权。传感器缺失在observer编码前移除带依赖的数据，教师完整数据只进入监督。缺失计划跨恢复和重放保持相同。

仿射驱动单独做消融；没有通过目标域、长时距和语义约束的模型不会自动进入生成部署。MSE未超过强基线时仍完整记录实验，不将研究实验中断伪装为成功。

## 入口与实际协议

新训练入口为 `python -m emotion_ssm.train.staged_v33.trainer --config CONFIG`。旧入口及旧权重的构造行为保留。新 kind 为 `dynamics_staged_v33`，训练版本为 `v3.3-query-balanced-endpoints-missing-replay-v1`，旧优化器不能恢复到该版本。

总控为 `scripts/run_staged_v33_suite.py`，依次运行1000步诊断，然后运行五个独立的10000步对照：vector_only、joint(0.25)、joint(1)、affine+joint(1)、affine+self-only+joint(1)。全部从同一个旧best权重显式初始化，不把诊断末态单独用于某组。后三者形成仿射开关与匹配的双人耦合对照。每组运行校准、固定起点预测、联合更新和重新适配四阶段。没有安排自动进入Avatar生成训练。

每步32个向量查询，按三个域11/11/10轮转；每个域内覆盖其实际存在的时距。标签另分配64个task查询，按域/时距/任务分层。一次抽到的向量起点只计算分配给它的时距；标签查询只计算分配给它的任务。64是标签任务预算，不是额外64秒视频。向量训练量为每角色向量平方L2；报告MSE再除以128。VAD以有效坐标数为分母，CE以标签查询数为分母，强度以有效强度查询数为分母。λ=0/0.25/1作用于新的分项归一化目标，不能直接与旧λ=1解释为同一损失强度。

校准和联合阶段使用逐域/时距的顺序查询游标：源对话顺序由固定种子确定，对话内按真实时间递增。首先按完整对话、完整缺失计划生成前缀状态库，再对抽到的起点并行重放最后32个事件并反传。32个事件以前的状态继续作为前缀保留，但梯度截断。该实现采用**带版本的截断前缀重放**，没有声称每一步都把全部历史用最新权重重新计算。前缀默认每250次update阶段优化步刷新；阶段切换后重建，并在readapt和live/gap验证中用最新权重完整重放，显式测量部署起点变化。刷新不改变游标或缺失计划。记录前缀生产者、刷新点、完整计划及恢复状态。

affine版本的连续驱动在两人间共享。`c = r_min * max_offset / sqrt(D) * tanh(parameter)`，其中r_min由当前全局时间常数和状态依赖阻尼的严格下界计算。因此参数和时间常数更新后仍满足每个快/慢驱动的`||c/r_min|| <= max_offset`。零初始化时与旧动力学相同。共享反馈仍可能改变完整系统的平衡点，需读取长时积分结果；该约束本身不证明学到了长时关系。

固定起点基线使用固定训练清单和初始生产者，中心+幅度校准随待测预测器在同一固定训练起点上重新拟合。live/update_gap/sensor_gap在同一训练清单上按对应生产者重放后拟合。全部拟合只使用train。各基线均通过同一冻结标签头评测真实端点。离散时距回归系数用于非整数端点时采取显式分段线性插值，零时距锚定保持；超过最后结点固定最后一组系数。共享连续收缩始终使用真实经过秒数。

每次验证保存四类输入协议下的域/时距/方法SSE、有效数量、逐会话结果、语义混淆矩阵和传播方向/幅度统计。`best_vector.pt`只按预设fixed宏MSE选择；`best_deploy.pt`还需通过目标域、长时距、语义与live/gap约束。`gate_passed`独立于`is_best`。没有best_deploy属于实验结论，不是程序故障。

## 绘图依赖与队列恢复

报表依赖单独列在`requirements-report.txt`，使用目标环境的`python -m pip install -r requirements-report.txt`安装。不要为补绘图依赖重新安装`requirements-v2.txt`，以免替换服务器已经验证的CUDA/PyTorch环境。总控获得队列锁后，先用同一Python执行`report_staged_v33_suite.py --check-environment`，实际验证Agg后端可生成PNG，再开始训练。
