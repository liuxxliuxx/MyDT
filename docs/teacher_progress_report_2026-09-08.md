**基于统一情感表征的交互式 Avatar：训练进展与问题汇报**

日期：2026 年 9 月 8 日。本文汇总截至本日已经核实的训练与实验记录，不代表新一轮服务器实时巡检。

当前已完成旧实验审计、新版数据与流式训练流程修复，以及四组公平条件下的诊断训练。上游情感识别和动力学预测已有一定效果，最终 Avatar 尚未获得稳定的增量收益。下一步重点是解决历史状态保留、训练与部署时间粒度，以及表达监督向动力学模块传递的问题。

**一、研究目标及数据的实际用途**

模型接收双方可见对话上下文、用户音频与头部 FLAME、Avatar 音频，以及历史情感状态；学习统一情感观测，再通过双人状态动力学描述事件后的持续、衰减、积累与 partner 影响，最后生成 Avatar 当前一秒的表情和头姿。

真实配对 FLAME 是完整条件下的表达示范。模型可以通过这些样本学习不同历史和语境下的表达方式及强度，不要求额外标注离散的“关切/安慰”策略。当前要验证的是历史状态是否帮助预测真实表达。

三份数据的分工是：EmotionTalk、IEMOCAP 用于上游情感观测与动力学训练，DualTalk 用于 FLAME 适配和生成训练。原 baseline control 实际只读取 DualTalk；不能表述为它也直接使用三份数据训练了相同的情感任务。

**二、各版训练出现的问题**

为方便说明，以下按三套实际训练流程划分，不另行设定仓库版本号。四个 none/affect/self/dyadic 是同一修复版中的独立对照，不是四次版本升级。

| 阶段 | 对应实验 | 已确认的问题 | 当时结果与限制 |
|---|---|---|---|
| 早期旧版 | 服务器 2 的 fold5 / all_three | 后期生成训练解冻 observer，表征明显退化；生成阶段逐块重置状态；情感路径只读音频；部分单源适配器选择错误 | 同为 3 轮、200 帧评测时，情感模型 test total 比 baseline 高约 0.31%；后期更多轮结果不能与 3 轮 baseline 直接归因比较 |
| 修复前新版 | 服务器 1 的 fold5_default200 等 | 已在同一文件内延续状态，但生成器冻结与对照预算冲突、部分主干永久 no_grad；评测有外部 observer 覆盖风险；数据语义、模态来源、事件和时间协议仍有问题 | 第 7 轮快照仍处于前 10 轮生成器冻结期，不能用它与已经微调主干的 baseline 判断结构优劣 |
| 当前流式修复版 | v2_retrain_20260907_gpu23 | 完成明确的数据、时序、训练权限和恢复问题修复；重训后仍暴露视觉迁移弱、历史更新过强、上游整句与部署一秒不匹配等问题 | A0/Phase A/Phase B 各 50 轮，FLAME 校准 3000 步，四组生成对照各 1000 步已完成；属于诊断预算 |

旧版生成器从第一轮就训练，冻结 10 轮的是 conditioner；修复前新版才存在生成器冻结问题。两者不能混为一谈。旧版第 3 轮 observer 尚未解冻，后期发现的塌缩也不能倒推为第 3 轮略差的原因。

**三、已经完成的修复及验证**

| 问题 | 实施的处理 | 已验证范围及剩余限制 |
|---|---|---|
| 生成训练破坏情感坐标 | 默认关闭未经可靠校准的一致性损失；固定 observer/SSM；A0 使用 EMA 与逐域逐模态防塌缩约束；增加方差、相似度和教师保持统计 | 阻断旧版的生成阶段漂移通路；当前上游不再整体接近常量。但冻结也使表达监督无法调整动力学，需后续适配设计 |
| 缺少真实多模态观测 | 接入带角色和可用时间的历史文本；新增独立 FLAME56 时序适配器；保留 AU35 接口与真实缺失 mask | 当前入口覆盖音频、文本和用户视觉；Avatar 当前目标 FLAME 被排除在条件输入之外。文本和视觉的有效覆盖仍不足 |
| 标签与特征来源混用 | EmotionTalk 保留 valence 和强度目标，屏蔽缺失 A/D；IEMOCAP 保留真实 VAD；适配器与实际音频/文本提取器绑定；单数据源自动选择 domain | 明确拒绝“维度相同即兼容”；强度不再冒充 arousal |
| 预处理质量不可靠 | 音频按有效输出长度池化，单独处理骨干 attention mask；保留人脸轨迹/角色接口；身份不明的 IEMOCAP 视觉屏蔽；缓存加入来源与版本摘要 | 新特征已重建。屏蔽不可靠输入保障语义，但没有补出缺失的真实视觉数据 |
| 文本可能提前可见或重复触发 | 提供 WAV/TXT 的 CTC 时间格与回溯对齐；低置信度或不支持文本置缺失；保留最近 256 token；只用新增文本触发事件 | 迟到文本只影响后续块，不重写历史；离线对齐与真实 ASR 协议分开 |
| 状态丢弃、滞后和事件偏置 | 使用持久 StreamState；按真实 dt 先衰减，再当前校正、一次事件注入；缺失事件显式零门控；视觉有效时允许校正 | 每次输出新增 25 帧，读取当前及过去 3 秒；同一片段内状态连续。缺少可靠跨文件映射时仍重置 |
| 长跨度预测协议含混 | A/B 按完整对话推进，32 个事件截断梯度但保留状态；open-loop 使用真实查询时间且不读取未来观测；conditional 只用明确提供的未来 event/action | 区分两类预测，加入 last-state、均值及纯衰减对照。上游仍以整句事件为单位，尚未与每秒部署完全适配 |
| baseline 与条件模型不公平 | 合并生成训练入口；四组统一数据顺序、上下文、有效新块、优化步、学习率和可训练主干；删除条件模型独有的永久 no_grad | 所有组从第一步训练同一主干，保留原音频卷积特征提取器冻结；none 仍有原始 partner AV |
| checkpoint 恢复语义不一致 | 保存构造配置、完整组件、来源、划分、协议与恢复状态；评测采用 checkpoint 内权重，不再随后覆盖 observer | 完整权重不依赖外部预训练文件恢复；旧语义权重只能显式兼容或作为新实验初始化 |
| 选 best 和误差汇总有偏差 | 从原 train 按原视频来源划出 10% val；test/OOD 不选 best；按纯 generation_total 选 best；使用 SSE/有效元素数汇总，去除 DDP 补齐重复样本 | 增加跨块边界速度误差；反事实分别报告候选覆盖、普通排序与 margin 成功率 |

代码验收覆盖因果性、目标视觉隔离、缺失事件、真实时间衰减、流式一致性、会话/角色隔离、恢复一致性、训练权限与加权指标。2026-09-07 本地与服务器部署时各有 82 项测试通过。物理 GPU 2、3 完成 NCCL 小模型检查及分布式校准梯度一致性检查。之后影响实验新增 8 项测试，并回归 31 项 v2 测试通过。这些是实现和小模型验证，不能代替真实数据效果验收。

部署时同步了 114 个代码、配置、测试与文档文件并核对 SHA-256，保留旧代码备份；使用服务器 1 的 lzh_DDG 环境和物理 GPU 2、3。训练队列覆盖特征重建、上游三阶段、FLAME 校准、四组生成及评测，失败时停止后续阶段。曾按要求自动监控，之后已按要求停止巡检。

**四、当前重训结果**

A0、Phase A、Phase B 各完成 50 轮；实际选中 A0 第 16 轮、Phase A 第 45 轮、Phase B 第 43 轮。FLAME 校准训练 3000 步，选中第 2500 步。四组生成器各训练 1000 步，每步全局 32 个有效新增块，种子均为 6666。正式 30000 步、三个种子的对照尚未开展。

当前 A0 选中权重在 EmotionTalk 验证集上的宏平均 F1：

| 输入 | F1 |
|---|---:|
| A | 0.4415 |
| V | 0.3209 |
| A+T | 0.5230 |
| A+V+T | 0.5577 |

上游多模态存在识别收益。V-only 平均样本余弦约 0.1728，不能概括为编码器全部输出常量。Phase B 在上游也有一定预测信号，但其综合损失与 Avatar FLAME MSE 不是同一种指标。

四组生成在相同独立验证集上的结果如下，均为 25 帧输出协议，验证有效帧数均为 575340。generation_total 是 expression、jaw、neck、块内 velocity 四项 MSE 的直接相加：

| 对照 | 条件 | expression MSE | generation_total |
|---|---|---:|---:|
| none | 无显式情感条件 | 0.295228 | 0.325965 |
| affect | 双方当前 affect | 0.294669 | 0.325392 |
| self | 当前 affect + 自身持续状态 | 0.295285 | 0.326020 |
| dyadic | 当前 affect + 双方持续状态 + relation/耦合 | 0.295519 | 0.326285 |

这些是用于选 best 的验证结果，不应写成独立 test 结果。当前 affect 有小幅点估计改善，self/dyadic 未显示增量优势；单种子 1000 步不构成稳定优劣结论。

**五、已经完成的三个针对性实验**

使用四组现有 checkpoint，在固定 test 片段上进行了推理干预，没有追加训练。历史/partner 实验使用 32 对片段，事件使用 19 对片段，合并为 100 个有方向片段、48 个原始视频。正常重放与真实流式前向的条件和输出最大绝对误差均为 0。

| 实验 | 控制方式 | 当前结果 |
|---|---|---|
| 历史影响 | 重置持续状态，保持后续原始 AV、当前 affect 和历史文本不变；经过 3 秒上下文后评分 | dyadic 输出有变化，但保留真实历史的 MSE 收益未得到稳定支持 |
| 事件持续、衰减与积累 | 比较删除、单次和重复事件；另用真实事件后 FLAME 评价轨迹 | 单次响应随时间减弱，重复事件增加响应；dyadic 事件中心化轨迹误差下降约 1.17%，边界速度误差下降约 0.78%，但属于少量片段上的次要指标 |
| partner 影响 | 只置换状态路线的 partner 观测，或关闭耦合；原生成器的 partner AV 不变 | 输出有变化，但真实 partner/耦合带来的 MSE 收益区间仍跨零 |

自然输入下，历史/partner 窗口的主要每秒平均 expression MSE 为 none 0.359241、affect 0.358445、self 0.362009、dyadic 0.360833。该批主要指标中，各条件模型相对 none 的来源聚类置信区间均跨零。

事件实验的两个局部改善尚未进行多重比较校正，且只有一个训练种子。none 对内部 SSM 干预零响应属于结构结果，不能据此说 baseline 没有情感能力。实验支持“通路会影响输出”，尚未支持“长时通路稳定改善表达”。

**六、重训后新定位的问题，尚未完成修复**

| 问题 | 证据与解释 | 下一步验证 |
|---|---|---|
| 历史被当前观测过强校正 | 默认状态与 affect 同维且 H=I；16 个真实方向片段、各 20 秒的 CPU 诊断中，双方校正门均值约 65%–68%。固定门控的直接历史路径每秒保留系数约 29%–31%，不等于整个系统的总遗忘率 | 比较部分观测映射或状态内快慢子空间，同时检查即时响应与长期预测，不能只调大 tau |
| 整句训练与一秒部署不匹配 | 上游按整句/当前发言人更新，部署每秒更新双方；文本整句事件变成词片段事件，校正频率和行为输入分布不同 | 在一秒因果协议下适配动力学、事件粒度与 action/reliability，再冻结进入生成对照 |
| FLAME 迁移仍弱 | 视觉校准余弦误差 0.20372，固定平均教师向量为 0.21776，仅改善约 6.45%；V-only 样本间余弦约 0.952；action 路线未单独验收 | 加强真实视觉/独立情感验证，确认视觉提供了超出 A/T 的有效信息 |
| 表达监督不能调整历史存储 | 为防止旧版语义漂移，当前生成阶段冻结 SSM，FLAME 损失不能调整其保留何种历史、保留多久 | 在固定情感坐标和教师保持约束下设计表达相关的适配阶段或受约束联合训练；避免回到无约束解冻 |
| 长期数据和事件覆盖不足 | DualTalk 没有可靠跨文件连续映射；6572 条角色文本未通过可靠对齐；现有测试仅 19 对合格事件片段，当前音量阈值几乎没有识别出倾听块 | 补齐文本/说话轮次质量检查，构建人工确认的事件与倾听验证子集；不靠文件编号拼接长期历史 |
| 与最初表征设想仍有差别 | 当前主要是池化特征上的 EMA 一致性和监督约束，尚未完整实现录音中讨论的模态内时间 token 遮挡恢复 | 将该表征方案作为独立消融，以情感指标和下游收益检验，不预设其必然优于现有方法 |

后续顺序是：先验证迁移表征与一秒动力学，建立表达监督与历史存储的联系，再运行同协议、同预算的正式多种子训练。研究方向保持为“历史与当前多模态条件共同决定 Avatar 表达”，当前不把缺少离散回应策略标签作为失败原因。

**可直接口头汇报的简版**

目前完成了三部分工作。首先核对了之前两套训练，发现早期版本后期解冻情感编码器后表征接近常量，生成阶段又没有跨块保留状态；另一套新版还存在主干冻结、适配器来源、评测恢复和时间协议不一致的问题。随后重做了统一的一秒流式训练流程，补入上下文和用户 FLAME，修复标签、缺失模态、状态更新、checkpoint 和公平对照，并完成代码测试。

现在 A0、单人和双人动力学都完成了 50 轮，FLAME 适配完成，none、affect、self、dyadic 四组各完成了 1000 步诊断训练。上游情感识别有收益，选中权重的多模态 F1 约 0.558，高于音频加文本的 0.523。但持续状态还没有给生成器带来稳定增益。历史重置、事件脉冲和 partner 置换三个实验已经跑完，通路会改变输出，整体预测质量的改善还不稳定。

目前定位到，状态每秒被当前观测强烈校正，上游整句训练又与每秒部署不一致；同时，为避免再次塌缩，生成阶段冻结了 SSM，真实 FLAME 监督无法调整历史该如何存储。下一步先在保持情感语义的约束下解决这些问题，再做正式长训。目标仍然是通过历史和当前条件下的真实表达示范，学会当前应该如何表达、表达多强。
