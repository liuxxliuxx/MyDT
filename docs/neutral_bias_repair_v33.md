# neutral偏置：诊断与拟议修复

状态：已独立核算现有逐终点预测。2026-09-11新增v3.4实现并通过本地和CUDA/NCCL校验，
正在服务器1执行独立实验。实际改动、参数、验收和日志见`docs/dynamics_v34_repair.md`。
以下保留原诊断与候选方案；margin等可选方案不代表本次全部启用。

## 已确认的现象

来源为2026-09-11统一评测的在线32秒真实终点结果。IEMOCAP有225个有效类别查询：
angry 79、happy 70、neutral 63、sad 6、surprise 7。

| 模型 | 保持起点时预测neutral | 传播后预测neutral | 非neutral误判neutral |
|---|---:|---:|---:|
| 旧9750 | 122/225 | 124/225 | 81/162 |
| vector-only 6500 | 164/225 | 212/225 | 150/162 |
| joint025 2000中途快照 | 141/225 | 132/225 | 89/162 |

保持起点是同一批未来查询对应起点的直接读出，不是起点真实标签准确率。
上述结果说明新起点的类别读出更集中于neutral，传播继续增加这种集中。
它不单独证明每一个变化都是错误；162个真实非neutral终点中150个被误判为neutral，直接证明未来类别辨别失效。

vector-only的IEMOCAP angry召回率为5/79，happy为7/70；旧版分别为31/79和37/70。
验证样本中neutral不是最多的类别。训练侧的有效类别分布仍需单独审计，不能由验证分布推断。
旧版也有明显偏置，因此仅蒸馏回旧版水平不足以完成修复。

## 实施顺序

1. 恢复真实语义训练。当前vector_only分支把整个分类损失系数设为0，仅修改CE的类权重没有作用。
   先在同一旧9750初始化、同预算下比较普通CE/VAD/强度联合目标，保留向量及当前语义约束。
2. 审计训练唯一终点数、有效抽样次数及实际梯度贡献，按数据域、预测时距、类别分别统计。
   若需要重平衡，先单独试验有上限的类平衡CE权重；权重仅来自训练集，按唯一真实终点计数。
   不同时叠加均匀过采样和逆频率损失权重；无支持类别不造监督，验证/测试维持自然分布。
3. 所有训练阶段检查在线起点漂移，更新传播器也要刷新状态生产者。继续冻结共享observer、教师及标签头。
   在实际在线起点上训练16/32秒真实语义，检验旧/新起点与旧/新传播器的完整交叉组合。
4. 追踪0/1/2/4/8/16/32秒的类别概率、neutral相对真实类别的logit差、状态范数、
   与固定baseline及训练均值的方向相似度，以及fast/slow抵消程度。
   区分潜在状态方向漂移、固定标签头的先验偏置和分量衰减，不凭argmax计数确认吸引点机制。
5. 如果正确时间和起点上的联合CE仍保留系统性的非neutral误判，再单独试验针对这些错误的margin项：
   L_margin = 1[y != neutral] * max(0, m + logit_neutral - logit_y)。
   保留neutral真样本的CE，且不得以该项取代其余类别间辨别；m及系数在开发流程预先确定。
   这是待验证的辅助实验，不与重平衡、蒸馏等所有候选一次性叠加。

## 验收

- 独立报告P(pred=neutral | y!=neutral)，按数据域和时距分组。
- 报告每类召回率、宏F1/UAR、neutral precision/recall和混淆矩阵。
- 修复非neutral误判不能通过把真实neutral全部预测成别的类别获得；同样检查反向错误。
- 比较保持、纯衰减、旧9750和线性预测器；只减少neutral比例不构成验收。
- 预测类别比例仅作诊断，不强迫它等于验证集比例或均匀分布。
- 无真实标签的DualTalk不能报告类别误判率；只能报告分布和动力学诊断。
- 共享标签头和教师保持不变；如果另做输出校准，所有基线使用同样开发协议并单独报告。

类平衡权重的参考方法：Cui et al., Class-Balanced Loss Based on Effective Number of Samples, CVPR 2019。
它处理类别训练不均衡，不能单独解决在线起点漂移和长时传播失效。
